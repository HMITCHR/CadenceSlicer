# Stock OrcaSlicer golden G-code

G-code from unmodified upstream OrcaSlicer at c806a09c7c
("Show current filaments at top of AMS filament dropdown (#11293)", 2.5.0-dev),
the upstream base of this tree. `test_mixed_nozzle_off.cpp` ("Off matches stock OrcaSlicer
G-code on the shared scenes") slices the same scenes with mode Off and requires the same
lines, apart from the ones `strip_nondeterministic_lines` drops (the "; generated by"
line with program, version and time, and per-run object ids).

Documented differences, all inside the trailing config block (comment lines only):
- this tree's own settings (`mixed_nozzle_*`, `regional_*`,
  `synchronized_multi_nozzle_layering`) are listed; stock does not have them;
- `different_settings_to_system` is listed, because this tree keeps it in the print config
  for the G-code handoff. Stock does not list it.
Every stock setting must be listed with the same value, and every line outside the config
block must match exactly.

Scenes are defined once in `tests/fff_print/stock_off_scenes.hpp`, which uses only
upstream config keys and upstream test helpers. Generated meshes only, no profiles:

- cube.gcode.gz: 10 x 10 x 3 mm box, default config, one nozzle.
- dual_nozzle.gcode.gz: two 8 x 8 x 2 mm boxes, two extruders (0.4/0.4, printer_extruder_id 1,2),
  one object per extruder, prime tower on.
- support.gcode.gz: the upstream `overhang` test mesh with supports on.

## How they were made

1. `git worktree add --detach <src> c806a09c7c`
2. Copy `tests/fff_print/stock_off_scenes.hpp` into `<src>/tests/fff_print/` and add
   `test_stock_golden.cpp` (below) to the `fff_print_tests` sources in
   `<src>/tests/fff_print/CMakeLists.txt`.
3. Configure: `cmake -S <src> -B <build> -G Ninja -DCMAKE_BUILD_TYPE=Release
   -DCMAKE_OSX_ARCHITECTURES=arm64 -DCMAKE_OSX_DEPLOYMENT_TARGET=11.3
   -DCMAKE_PREFIX_PATH=<OrcaSlicer deps prefix> -DSLIC3R_STATIC=ON -DSLIC3R_PCH=ON
   -DORCA_TOOLS=OFF -DBUILD_TESTS=ON` (macOS arm64, same deps as this tree).
4. `ninja -C <build> -j2 fff_print_tests`
5. `STOCK_OFF_OUT=<out> <build>/tests/fff_print/fff_print_tests.app/Contents/MacOS/fff_print_tests "[StockGolden]"`
6. `gzip -n -9 -c <out>/<scene>.gcode > <scene>.gcode.gz` (no file name or time in the header;
   the test reads it with miniz).

```cpp
#include <catch2/catch_all.hpp>
#include "stock_off_scenes.hpp"
#include <cstdlib>
#include <fstream>

TEST_CASE("Write stock golden G-code", "[StockGolden]")
{
    const char *out = std::getenv("STOCK_OFF_OUT");
    REQUIRE(out != nullptr);
    for (const std::string &name : StockOffScenes::names()) {
        const std::string gcode = StockOffScenes::slice(name);
        REQUIRE_FALSE(gcode.empty());
        std::ofstream(std::string(out) + "/" + name + ".gcode", std::ios::binary) << gcode;
    }
}
```

Regenerate only from an upstream commit, never from this tree. If the upstream base moves,
regenerate all three and update the commit above.
